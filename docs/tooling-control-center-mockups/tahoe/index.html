Agent Tooling · macOS 26 · design pass 3

One window, real glass, fewer words.

Three earlier passes each got one thing right. Glasshouse v4 had the material and the colour identity you asked for. The August canvas had the information architecture, a single state language, and a world of sample data that agrees with itself. The native prototype has the right bones. This pass keeps all three and makes the window read as a macOS 26 app: a translucent sidebar over a calm desktop, capsule controls on an opaque pane, colour reserved for what a thing is and for the one thing that needs you.

Eleven screens, every one in light and dark. Paths sit behind ⓘ popovers that work in this mockup. Type is SF Pro through the system stack, so open it on a Mac.

Material

One glass sheet. The window and its sidebar blur the desktop; the content pane is a 90% paper inset with a concentric radius. Sheets are deeper frost. Nothing else is translucent, so text never fights the wallpaper.

Identity, not status

SkillPluginMCP serverProfileSelection

Tiles say what a thing is; the three brand marks say where it runs. Green, amber and red appear only as small glyphs beside words.

Type & density

SF Pro at 13 and 11.5, one 19px name per screen, SF Mono only for revisions and commands. Every row is a tile, a name, one clause, and a verdict.

Words that do work

File locations live behind ⓘ with a Reveal in Finder link. Buttons say what will happen: Sign In…, Adopt…, Apply 6 Changes…. Nothing writes to a client outside Sync Review.

What carried over, what changed

The screens above are a synthesis, not a fourth direction. Here is where each part came from, and what a SwiftUI build should reach for.

Kept from the August canvas

  • IA. Overview · Recommendations · Discover / Library · MCP Servers · Sync · Activity / one page per client. Settings is its own window.
  • State language. Desired, discovered (dashed), installed, verified (seal + time), needs attention (amber + one action), will change (checked rows).
  • One world. Plan S-118 applied yesterday, S-119 pending with six changes, backup B-143 next, Sentry sign-in expired Thursday, developer-workflows update waiting.

Restored from Glasshouse v4

  • Glass. A luminous desktop refracting through the sidebar and window edge; the paper stays opaque enough to read.
  • Icon vocabulary. Orange skill, purple plugin, teal MCP, indigo profile tiles, plus the real Claude, Codex and Gemini marks for availability.
  • Fewer words. No paths in rows. Hover the ⓘ on Skill, MCP Servers, Discover, and Claude Code to see the location popover.

New in this pass

  • The conduit. Overview draws library → profile → clients as one path, with pending changes on the trunk and a verdict at each terminal.
  • Tahoe controls. Capsule buttons, 20px window radius, concentric 14px pane, a menu bar in the scene so the glass has something to refract.
  • Evidence panes. Recommendations shows the sessions behind a suggestion; Skill shows its history and files; Activity expands a receipt in place.

Hand-off to SwiftUI

Everything on these screens maps to existing native material; nothing needs a custom renderer.

Material

  • Window & sidebar — the existing DesktopGlassBackground (NSVisualEffectView, behind-window) at full strength instead of 0.96 opacity; sidebar rows on .glassEffect().
  • Paper — RoundedRectangle(14, .continuous) filled with .windowBackgroundColor at 0.90, inset 8pt.
  • Sheets — standard .sheet with .presentationBackground(.thickMaterial).

Components

  • Capsules — .buttonStyle(.glass) / .borderedProminent with .buttonBorderShape(.capsule).
  • Tiles — SF Symbols doc.text, puzzlepiece.extension, server.rack, slider.horizontal.3 on 8pt rounded fills of systemOrange, systemPurple, systemTeal, systemIndigo.
  • Marks — the existing ClientBrandIcon; dimmed at 22% + grayscale for “not available here”.

State & motion

  • Glyphs — checkmark.circle.fill, exclamationmark.triangle.fill, xmark.circle.fill, arrow.up.circle; always beside a label.
  • Popovers — .popover from an info.circle button with a Reveal in Finder link.
  • Conduit — a Path with a phase-animated dash while a plan is pending; gated on accessibilityReduceMotion.
