# Online Research

Research a topic and synthesize actionable findings.

$ARGUMENTS

## Workflow

1. **Understand the question**: Identify what specific information is needed and how it relates to the PUMPD codebase.

2. **Search strategy** (use in parallel when possible):
   - Web search for general information, blog posts, and comparisons.
   - Direct page fetch/open for documentation pages or GitHub READMEs.
   - A version-aware documentation capability such as Context7 for library-specific APIs, when available.

3. **Evaluate sources**: Prioritize in this order:
   - Official documentation
   - Library GitHub repos (READMEs, changelogs)
   - High-quality blog posts and tutorials
   - Stack Overflow / GitHub Issues

4. **Synthesize**: Provide a structured summary with:
   - **Answer**: Direct answer to the research question.
   - **Key findings**: Bullet points of important information.
   - **Relevance to PUMPD**: How this applies to the project.
   - **Code examples**: If applicable, adapted to PUMPD conventions.
   - **Sources**: Links to all sources used.

5. **Recommendations**: If the research was about choosing a library or approach, provide a clear recommendation with rationale.
